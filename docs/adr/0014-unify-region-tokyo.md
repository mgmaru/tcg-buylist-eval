# 0014. リージョンは東京に統一する

- ステータス：採用
- 日付：2026-10-27
- 決定者：kajiwara
- 記録：[AWSのアカウントの準備](../setup/aws-account.md) 3.2

## 背景

- GPUサーバーは、米国東部（us-east-1）の g6.xlarge を使うと決めていた（[0005](0005-gpu-environment.md)）。理由は、東京より35〜45%安いため。Langfuseのサーバーも、同じ米国東部に置くと決めていた（[0010](0010-self-host-langfuse.md)）。
- 決定者は、リージョンを東京に統一したいと考えている。また、GPUサーバーを海外に置くと通信料が発生するのではないか、という懸念があった。
- AWSのアカウントの準備で、IAM Identity Centerを有効にするときにリージョンを選ぶ必要があった。IAM Identity Centerのリージョンは、あとから変えられない。

通信料は、GPUサーバーが海外にあるからかかるのではなく、データがどこからどこへ流れるかで決まる。

| データの流れ | 料金 |
|---|---|
| インターネットからAWSに入る通信 | 無料 |
| AWSからインターネットへ出る通信 | 有料。ただし毎月100GBまでは無料の枠がある |
| リージョンをまたぐ通信 | 有料 |
| 同じリージョンの中の通信 | 同じアベイラビリティゾーンの中なら、ほぼ無料 |

すべてのリソースを同じリージョンにまとめれば、東京でも米国東部でも、通信料はほぼかからない。通信料が問題になるのは、リソースを複数のリージョンに分けた場合。

## 検討した選択肢

月の費用（GPUサーバー、実行環境、ディスクなどの合計。[AWSの費用の調査](../research/aws-gpu-cost.md) より）：

| GPUを使う時間 | 米国東部 | 東京 | 差 |
|---|---|---|---|
| 5時間 | 約880円 | 約1,220円 | +約340円 |
| 10時間 | 約1,650円 | 約2,320円 | +約670円 |
| 30時間 | 約4,700円 | 約6,690円 | +約2,000円 |

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| 米国東部に統一する | GPUサーバーが最も安い（g6.xlarge：0.8048ドル／時間） | データを米国に置く。画面の反応が少し遅い |
| **東京に統一する** | リージョンを取り違えない。画像などのデータを日本に置ける。画面の反応が速い | GPUサーバーが高い（g6.xlarge：1.1672ドル／時間）。GPUの予算（月5,000円）で使える時間が約36時間から約25時間に減る |
| 東京と米国東部に分ける（GPUサーバーだけ米国） | GPUサーバーは安い | リージョンをまたぐ通信料がかかる。構成が分かりにくい |

## 決定

- **リージョンは、すべて東京（ap-northeast-1）に統一する。** 対象は、GPUサーバー、エージェントの実行環境、Langfuseのサーバー、S3、Terraformの状態ファイル、IAM Identity Centerなど。
- GPUサーバーのインスタンスの種類（g6.xlarge、L4・24GB）は、[0005](0005-gpu-environment.md) のまま変えない。
- GPUの利用枠（G・VTインスタンスのオンデマンド）は、**東京で** 8 vCPU申請する。

この決定で、次の部分を置き換える。

- [0005](0005-gpu-environment.md) の「リージョンは米国東部（us-east-1）。米国西部（us-west-2）は同じ価格なので予備とする」と「GPUの利用枠を、米国東部で8 vCPU申請する」
- [0010](0010-self-host-langfuse.md) の「リージョンは、ほかのサーバーと同じ米国東部（us-east-1）」

## 影響

- M0なら、月の費用の増加は数百円程度で、全体の予算（月1万円）に収まる。
- GPUの予算（月5,000円）で使える時間が減る。M2で回数が増えたときに、早めに予算に届く。M1の判断のときに見直す（TODO 13章）。
- Langfuseのサーバーも、東京の料金になる（米国東部より2〜3割程度高い見込み）。
- 東京でGPUサーバーの空きがないときの予備のリージョン（大阪など）は、インフラの設計で必要かを決める。g6.xlarge が使えるかの確認も含む。
- Opus 5.5のAPIに送る画像は、これまでどおり米国のサービスに渡る。利用規約・権利の確認は、この前提で行う（TODO 2章）。
- 使えるリージョンを東京に限るルール（SCP）を付けるかは、アカウントの構成と一緒に決める（TODO 5章）。
