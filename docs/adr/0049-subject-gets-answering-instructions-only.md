# 0049. 被験エージェントには回答の仕方だけを伝え、採点の仕組みは伝えない

- ステータス：採用
- 日付：2026-10-31
- 決定者：kajiwara
- 関係するADR：[0030](0030-task-spec-in-yaml.md)（タスクの仕様と伝え方）、[0032](0032-separate-files-by-reader.md)（読み手ごとのファイル）、[0037](0037-results-and-diagnosis.md)〜[0039](0039-deliverables-and-intermediates.md)（成績と診断）、[0047](0047-output-reading-and-answer.md)（reading と answer）

## 背景

- 採点の仕組み（成績と診断、正解・保留・誤答の決め方、どの項目を成績に使うか）を決めた（[0037](0037-results-and-diagnosis.md)〜[0039](0039-deliverables-and-intermediates.md)）。
- 出力の形を見直す中で、`intermediate`（中間結果）と `final`（最終結果）という名前の案が出た。しかし、この名前は「どこが成績に使われるか」を、被験エージェントに教えることになる（[0047](0047-output-reading-and-answer.md)）。
- 被験エージェントは、テストを解く人にあたる。テストを解く人は、問題と、回答の仕方の注意書き（「わからない問題は空欄にしてよい」など）を読んで答えを書く。採点基準（どの欄が何点か、合格点は何点か）は知らされない。
- 被験エージェントが採点の仕組みを知ると、本当の解く力ではなく、点の取り方を測ることになる。評価のときだけ点を取りにいく振る舞いをすると、評価の結果が本番（Card Pulse での取り込みなど）の振る舞いを表さなくなる。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| A. 採点の仕組みも伝える | エージェントが、評価で点を取りやすい答え方をする | 点の取り方を測ることになる。評価と本番で、振る舞いが変わるおそれがある |
| **B. 回答の仕方（注意書き）だけを伝え、採点の仕組みは伝えない** | 評価の結果が、本番の振る舞いを表す | 伝えてよいものと、いけないものの線引きが要る |

## 決定

**B にする。** 被験エージェントに渡すもの（タスクの仕様をもとにしたプロンプト、出力のスキーマ）には、次のように線を引く。

| | 例 | 被験エージェントに |
|---|---|---|
| **回答の仕方**（テストの注意書きにあたる） | 確信がなければ不明と答えてよい。間違ったカードを答えるより、不明と答える方がよい。画像にないことは推測で埋めない。価格は円の整数で答える。値は決められた一覧から選ぶ | **伝える** |
| **採点の仕組み** | どの項目で成績を決めるか（成果物と中間結果）。正解・保留・誤答の決め方。合格ライン。診断の分け方。採点に使うか使わないか | **伝えない** |

- 迷ったときは、**本番でも同じ指示をするか** で決める。本番でも同じ指示をするものは、回答の仕方として伝えてよい。評価のときだけのものは、伝えない。
- 出力のスキーマのプロパティの名前と説明も、中身を表すものにし、採点の仕組みを表す言葉（「採点」「成績」「誤答」「保留」「合格」など）を使わない。
- 被験ハーネスのプロンプト（TODO 9章）を書くときも、この決まりに従う。

## 理由

- **評価の結果が、本番の振る舞いを表すようにするため。** 評価は、本番でどれだけ正しく答えられるかを確かめるためにある。採点の仕組みを知ったエージェントは、評価のときだけの振る舞いをするかもしれない。A を選ばなかったのはこのため。
- **回答の仕方は、本番でも同じだから伝える。** 「間違ったカードを答えるより、不明と答える方がよい」は、採点基準ではなく、本番でも守ってほしい答え方の注意書きである。伝えなければ、エージェントは何を求められているかがわからない。
- **線引きの基準を「本番でも同じ指示か」にするのは、** 迷ったときに、評価の都合ではなく、本番で求める振る舞いに照らして決められるため。

## 影響

- 被験エージェントに渡す側のファイル（`spec.yaml` の決まりの本文、`output.schema.json`）に、採点の仕組みを表す言葉が入っていないことを確かめた。今後、これらを直すときも確かめる。
- 被験ハーネスのプロンプトを書くとき（TODO 9章）、レビューでこの決まりを確かめる。
- 正解データの作り方（`gold-guideline.yaml`、`gold-draft/prompt.md`）は、被験エージェントには渡さない（[0032](0032-separate-files-by-reader.md)）。この決まりの対象外。
