# 0006. クラウドのモデルの認証：APIキー

- ステータス：採用
- 日付：2026-10-26
- 決定者：kajiwara
- 調査：[クラウドのモデルのAPI代](../research/cloud-model-api-cost.md)

## 背景

- 設計書では、手元のサブスク認証のまま実行する方針だった（設計書 7.2）。
- 被験エージェントは、隔離された環境やクラウドのサーバーで無人実行する（[0003](0003-isolated-execution-environment.md)、[0005](0005-gpu-environment.md)）。
- M0の実行スクリプトは、モデルのAPIを直接呼ぶ（[0008](0008-execution-framework.md)）。
- QCDの「コスト」を測るには、トークン数や費用を正確に取れるほうがよい。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| サブスク認証 | 追加の費用がかからない（利用枠の範囲内） | サブスクで使えるのはClaude CodeなどのAnthropicのアプリだけで、APIを直接呼ぶ使い方はできない。Claude Code経由にすると、ローカルのモデルとランタイムが揃わない。サーバーでの繰り返しの無人実行が利用規約上できるか、はっきりしない。費用を正確に測りにくい。普段の作業と利用枠を取り合う |
| APIキー（従量課金） | 無人実行に向いている。トークン数と費用を正確に記録できる | 実行するたびに費用がかかる。キーを安全に管理する必要がある |

Opus 5.5のAPI代の見込み（1ドル＝160円）：

| 段階 | 費用 |
|---|---|
| H0の1回 | 約22〜85円（標準で約43円） |
| M0（試しの実行を含めて約30回） | 約700〜2,600円 |
| M2（10タスク × H0〜H3 × 3回） | 約4,800〜33,000円（標準で約13,000円） |

## 決定

- クラウドのモデルは **APIキー** で呼ぶ。
- Anthropicのコンソールに **この評価専用のワークスペース** を作り、**利用額の上限（月30ドル程度）** を設定する。
- APIキーは **AWSのSSMパラメータストア（SecureString）** に保存する。リポジトリには入れない。
- API代は月1万円の予算に含めて管理する。
- 速さも測るので、通常のAPIを使う。Batch API（半額だが結果が返るまで時間がかかる）は、M2以降に正答率だけを見る繰り返し実行で検討する。

## 影響

- 設計書 7.2（サブスク認証で動かす）を見直す。
- 実行記録（`run.yaml`）に、トークン数、費用、プロンプトキャッシュを使ったかどうかを残す（設計書 5.5）。キャッシュを使うと速さの測定がずれるため。
- M2はAPI代とGPU代を合わせると月1万円を超える見込み。月をまたいで分けて実行するなどの方法を、M1の判断のときに決める。
- サブスクは、M2以降にClaude Codeそのものを被験ハーネスとして使う場合に、利用規約を確認したうえで見直す。
