# 0054. 結ぶマスのない答え（余分）は、断定していれば誤答に数える。分母は正解データの枚数のまま

- ステータス：採用
- 日付：2026-11-03
- 決定者：kajiwara
- 関係するADR：[0028](0028-unnumbered-cards-out-of-m0.md)（M0の対象外のカード）、[0038](0038-score-by-assertion.md)（成績：正解・保留・誤答）、[0052](0052-matching-procedure.md)（対応付けの手順）、[0055](0055-competing-answers-for-one-cell.md)（1つのマスに結べる答えが複数あるとき）
- 採点の段階：段階2（成績を付ける）。段階1から渡される「③ 結ぶマスのない答え」と、対象外のマスと結ばれた答えに、成績を付ける

## 背景

- 採点は、「対応付け」（段階1）と「成績を付ける」（段階2）の2つの段階に分かれる（[0052](0052-matching-procedure.md) の図）。段階1のあと、どのマスとも結ばれない答えが残ることがある。これを **余分** と呼ぶ。たとえば、「5-1：リザードン」のように買取表に載っていないカード、広告や見出しをカードとして読んだもの、同じ答えを2回書いたもの、である。
- 余分に似たものに、**対象外のマスへの答え** がある。番号が印刷されていないカードなど、正解データから外したカード（[0028](0028-unnumbered-cards-out-of-m0.md)）への答えである。外したカードは、`meta.yaml` の `excluded` に、位置と名前が残っている。この答えは、段階1で、外したカードのマス（対象外のマス）と結ばれる（[0052](0052-matching-procedure.md)）ので、余分ではない。ただ、成績の付け方は、ここで一緒に決める。1枚目にはない。
- 試験なら、問題にない答えは無視されて終わりである。しかし確定データでは、ないカードの記録が、そのまま偽の記録として残る。
- 誤答率などの割合の分母は、正解データの枚数（買取表のカードの枚数）である。余分は、買取表のカードではない。

## 検討した選択肢

余分（本当にないものへの答え）について：

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| **A. カードか価格を断定していれば、誤答に数える。分母は正解データの枚数のまま** | ないカードの記録が、誤答率に表れる | 正解率・保留率・誤答率の合計が、100％を超えることがある |
| B. 成績には数えず、診断だけ | 単純 | ないカードを作り出す被験ハーネスでも、誤答率が低く見える |
| C. 分母に足す（正解データの枚数＋余分） | 合計が100％になる | 正解率の意味（買取表のどれだけを、正しく取れたか）が変わる |

## 決定

**A にする。** 段階2で、次のように成績を付ける。

| 段階1から渡されるもの | 成績 | 診断に記録すること |
|---|---|---|
| 対象外のマスと結ばれた答え | 数えない | 対象外のマスへの答え |
| 余分で、カードか価格を断定している | **誤答** | 余分 |
| 余分で、何も断定していない（不明で、価格もnull） | 数えない | 余分（断定なし） |
| 余分で、すでに結ばれた答えと、まったく同じ中身（同じカード・同じ価格） | 数えない | 重複 |

- 割合の分母は、これまでどおり正解データの枚数とする。
- 誤答の内訳を、「正解データのカードを間違えた」と「ないカードを断定した」の2つに分けて出す。

### 割合の合計が100％を超えること

割合ごとに、分母と答える問いが違う。

| 指標 | 分母 | 答える問い | 余分の断定 |
|---|---|---|---|
| 正解率 | 正解データの枚数 | 買取表のどれだけを、正しく取れたか | 入らない |
| 保留率 | 正解データの枚数 | 人が確かめる量は、どれくらいか | 入らない |
| 誤答率 | 正解データの枚数 | 確定データを、どれだけ汚すか（買取表のカード1枚あたり） | 分子に入る |
| 適合率 | 断定した答え（正解＋誤答） | 断定した答えを、どれだけ信用できるか | 分母にも、分子の誤答の側にも入る |

余分の断定があると、正解率・保留率・誤答率の合計は100％を超える。例：正解データが40枚で、正解36・保留2・誤答2、さらに余分の断定が1つあったとき。

| | 件数 | 割合 |
|---|---|---|
| 正解 | 36 | 90％ |
| 保留 | 2 | 5％ |
| 誤答 | 2（正解データのカード）＋1（ないカード） | 7.5％（5％＋2.5％） |
| 合計 | | 102.5％ |

- 100％を超えた分（2.5％）は、ちょうど「ないカードを断定した割合」になる。余分の断定がなければ、合計はちょうど100％になる。合計が100％を超えるのは、矛盾ではなく、ないカードを作り出したことの表れとして読める。
- 適合率は、36 ÷（36＋3）＝ 約92.3％になる。分子（正解）は分母の一部なので、100％を超えることはない。

## 理由

- **ないカードの記録は、確定データを汚すため。** 断定した余分は、そのまま取り込めば偽の記録になる。成績の問い（[0038](0038-score-by-assertion.md)）では、誤答に当たる。B を選ばなかったのはこのため。数えなければ、ないカードを作り出す被験ハーネスでも、誤答率が低く見える。
- **正解率の意味を変えないため。** 正解率は「買取表のどれだけを、正しく取れたか」を表す。分母に余分を足すと、正しく取れた量が変わっていないのに、正解率が下がる。C を選ばなかったのはこのため。合計が100％を超える点は、誤答の内訳を出して補う。
- **何も断定していない余分は、データを汚さないため。** 不明で価格もnullの答えは、取り込んでも記録にならない。成績には数えず、被験ハーネスを直す手がかりとして、診断にだけ残す。
- **対象外のマスへの答えは、採点しないため。** エージェントは、どのカードが対象外かを知らない。対象外のカードに答えても、責められない。
- **まったく同じ中身の重複は、データを汚さないため。** 同じ記録が2回入るだけである。
