# 0005. ローカルモデルを動かすGPU環境：AWSかWindows PCか

- ステータス：提案
- 日付：2026-10-26
- 決定者：kajiwara

## 背景

- ローカルのマルチモーダルモデル（[0002](0002-compare-cloud-and-local-models.md)）を動かすGPU環境が必要。作業用のMacでは動かさない。
- 候補は、手元にある別のWindows PC（RTX 3080、VRAM 10GB）か、クラウドのGPUサーバー。クラウドはAWSを使いたいが、コストを調べてから決める。
- 予算：GPUサーバーは月5,000円程度、ほかのサーバー代も合わせて月1万円程度。
- M0の実行回数は少ない（例：2モデル × 3タスク × 3回 ＝ 18回）。GPUを使う時間は数時間で済む見込み。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| Windows PC（RTX 3080・VRAM 10GB） | 費用は電気代だけ | 動かせるのは量子化した7〜8Bクラスまで。エージェント側からの接続（ネットワークの公開と安全性）を考える必要がある。IaCの経験はWindows（WSL2）の構成管理が中心になる |
| AWSのGPUサーバー（使うときだけ作る） | IaCの経験が最も積める。VRAM 16〜24GBのGPUを選べる。エージェントの実行環境と同じ場所にまとめられる | 時間課金がかかる。新しいアカウントではGPUサーバーの利用枠の申請が必要なことが多い |
| AWS以外のGPUクラウド | AWSより安いことがある | 目的の「AWSでのIaCの経験」から外れる |

AWSの費用の目安（調査前の目安。正確な価格はTODOで調べる）：

| インスタンス | GPU | オンデマンドの単価 |
|---|---|---|
| g4dn.xlarge | T4・16GB | 約0.5〜0.7ドル／時間 |
| g6.xlarge | L4・24GB | 約0.8〜1.1ドル／時間 |
| g5.xlarge | A10G・24GB | 約1.0〜1.5ドル／時間 |

月5,000円（約33ドル）では、およそ30〜60時間使える。

## 決定（提案）

おすすめは、**エージェントの実行環境もモデルのサーバーもAWSにまとめ、使うときだけTerraformで作る** こと。Windows PCは、GPUの利用枠の申請が通らないときや、モデルを手元で試すときの予備とする。

採用にするために必要なこと：

- AWSの費用を調べる：GPUのインスタンス、リージョン（東京と米国の差）、ディスク、モデルの重みの保存（S3）、データ転送
- GPUサーバーの利用枠の申請が通るか確認する
- クラウドのモデルのAPI代を月1万円の中に含めるかを決める（[0006](0006-cloud-model-authentication.md)）

## 影響

- AWSにする場合：消し忘れが一番の費用リスクになる。予算のアラートと削除の手順を最初に用意する（[0004](0004-infrastructure-as-code.md)）。
- サーバーを消しても費用が残るもの（ディスク、S3など）を把握しておく。
- Windows PCにする場合：エージェントの実行環境からの接続方法と、その安全性を決める。
