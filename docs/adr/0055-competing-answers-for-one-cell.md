# 0055. 1つのマスに結べる答えが複数あるときは、読んだものが正解とより合う答えを結ぶ

- ステータス：採用
- 日付：2026-11-03
- 決定者：kajiwara
- 関係するADR：[0038](0038-score-by-assertion.md)（成績：正解・保留・誤答）、[0051](0051-position-shift-not-graded.md)（位置と印刷名で対応付ける）、[0052](0052-matching-procedure.md)（対応付けの手順）、[0054](0054-extra-answer-counted-as-wrong.md)（余分）

## 背景

- 採点は、「対応付け」と「成績を付ける」の2つの段階に分かれる（[0052](0052-matching-procedure.md) の図）。
- 答案の中に、同じ位置（段・列）を書いた答えが2つある場合がある。出力のスキーマでは防げない。試験でいうと、1つの欄に答えを2つ書いた場合である。
- 対応付けの手順（[0052](0052-matching-procedure.md)）では印刷名でも結ぶので、ほとんどの場合は、手順だけで片付く。決まらないのは、3つ目のパターンだけである。

| パターン | 例 | どうなるか |
|---|---|---|
| 印刷名が違う | 1-4：ヤドン と 1-4：ヤドキング | ヤドンは1-4と結ばれる。ヤドキングは、印刷名で1-7と結ばれる（位置ずれ）。印刷名が買取表のどこにもなければ、余分（[0054](0054-extra-answer-counted-as-wrong.md)） |
| 中身がまったく同じ | 1-4：ヤドン（2,000円）が2つ | 1つは1-4と結ばれ、もう1つは余る。重複になり、誤答にしない（[0054](0054-extra-answer-counted-as-wrong.md)） |
| **印刷名は同じで、中身が違う** | 1-4：ヤドン（2,000円）と、1-4：ヤドン（1,500円） | どちらも、1-4のヤドンへの答えに見える。どちらを結ぶか、決まらない |

## 検討した選択肢

印刷名は同じで、中身が違うときについて：

| 選択肢 | 中身 | 結果（2,000円が正しいとき） | 弱い点 |
|---|---|---|---|
| **A. 読んだものが、より合うほうを結ぶ** | HP・価格の文字が、マスの正解とより合う答えを結ぶ。残りは余分にする（中身が違うので、断定していれば誤答） | 正解1、誤答1 | 読んだものまで同じときは、決まらない |
| B. 1件にまとめて、悪いほうで数える | 2つを1つの答えとみなし、どちらかが間違っていれば、誤答として1件だけ数える | 誤答1 | 正しいほうの記録まで、誤答として数える |
| C. そのマスを保留にする | 食い違いは、人が確かめるとみなす | 保留1 | 取り込む前に食い違いを見つける仕組みを、前提にしている |

## 決定

**A にする。**

- 1つのマスに、結べる答えが複数あるときは、読んだもの（HP・価格の文字）が、マスの正解とより合う答えを結ぶ。
- 残りの答えは、余分として扱う（[0054](0054-extra-answer-counted-as-wrong.md)）。中身が違い、カードか価格を断定していれば誤答、中身がまったく同じなら重複（数えない）。
- 読んだものまで同じで、答えだけが違うときは、先に書かれたほうを結ぶ。
- 同じ位置に答えが複数あったときは、どのパターンでも、診断に「同じ位置に複数の答え」と記録する。格子の把握（H1：分割）を直す手がかりになる。
- この決まりは、同じ位置に限らず、1つのマスに結べる答えが複数あるとき（たとえば、対応付けの手順2で、同じ印刷名の答えが2つあるとき）にも使う。

## 理由

- **答案を「そのまま」取り込んだ結果と合うため。** 成績の問いは、「断定した答えを、そのまま確定データとして使ってよいか」である（[0038](0038-score-by-assertion.md)）。答案をそのまま取り込めば、2つの記録が両方入る。A は、その結果（正しい記録1つ、間違った記録1つ）を、そのまま数える。
- **B を選ばなかったのは、** 正しいほうの記録まで誤答として数え、実際より厳しくなるため。
- **C を選ばなかったのは、** 取り込む前に食い違いを見つける仕組みを前提にしていて、「そのまま」に合わないため。
- **答えではなく、読んだもので選ぶため。** 対応付けに答え（カードと価格の組み合わせ）を使わない、という決まり（[0051](0051-position-shift-not-graded.md)）と合う。
- **先に書かれたほうを結ぶのは、** 読んだものまで同じで答えだけが違うことは、めったに起きないため。そのときだけは、ほかに選ぶ手がかりがない。
