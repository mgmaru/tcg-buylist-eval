# 0048. 価格の null は「控えた」として保留にし、誤答にしない

- ステータス：採用
- 日付：2026-10-31
- 決定者：kajiwara
- 関係するADR：[0036](0036-stamp-none-when-not-seen.md)（スタンプの「なし」と「指定なし」）、[0038](0038-score-by-assertion.md)（正解・保留・誤答）、[0039](0039-deliverables-and-intermediates.md)（成果物と中間結果）、[0040](0040-intermediate-results-for-diagnosis.md)（価格の文字）

## 背景

- 価格（`answer.price_jpy`）は成果物で、断定して間違えれば誤答になる（[0039](0039-deliverables-and-intermediates.md)）。
- 価格が画像にはっきり書かれているのに、エージェントが null を返すことがありうる。これは明らかな失敗で、誤答にすべきではないか、という意見があった。
- 一方で、価格の null（`reading.price_text` と `answer.price_jpy` の null）は、今は2つの意味を兼ねている。
  - 価格が **書かれていない**（ないことを断定している）
  - 価格が **読み取れない**（控えている）
- これは、スタンプの「なし」と「指定なし」と同じ関係である（[0036](0036-stamp-none-when-not-seen.md)）。
- 買取表で、価格が書かれていないマスは、ほとんどない。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| **A. null は「控えた」とし、正解に価格があれば保留にする。診断で「価格の読み落とし」として記録する** | 控えることが、間違えるより損が小さいままになる。決まりが単純 | 「価格が書かれていない」と断定する手段がない |
| B. null を、正解に価格があれば誤答にする | 読み落としを重く罰する | 控えても誤答なら、当て推量で書いたほうが得になる。間違った価格が増える |
| C. 「書かれていない」と「読み取れない」を分ける | 「あるのにないと断定した」は誤答、「読み取れない」は保留、と分けられる | 項目と決まりが増える。M0の買取表には、価格のないマスがほとんどない |

## 決定

**A にする。**

- 価格の null は、**「控えた」（断定していない）** として扱う。
- 正解に価格があり、出力が null なら、価格は **保留** とする。カードの成績は、ほかの成果物とあわせて決める（[0039](0039-deliverables-and-intermediates.md)）。
- 正解に価格がなく、出力が null なら、価格は合っているものとする。
- 正解に価格がないのに、出力が価格を断定したら、**誤答** とする（ない価格を作った）。
- 診断では、「正解に価格があるのに null」を **価格の読み落とし** として記録する。直す部品は、画像の読み取り。

## 理由

- **控えることが、間違えるより損が小さいという関係を、価格でも保つため。** null を誤答にすると、控えても誤答なので、自信がなくても当て推量で書いたほうが得になる。その結果、間違った価格（確定データを汚すもの）が増える。誤答を一番重く見る方針と逆の振る舞いを招く。B を選ばなかったのはこのため。
- **読み落としは、成績と診断の両方に表れるため。** 読み落としたカードは正解にならず保留になるので、正解率が下がり、合格ライン（正解率80％以上）に効く。診断でも「価格の読み落とし」として見える。誤答にしなくても、失敗は隠れない。
- **C は、今は要らないため。** 買取表で価格が書かれていないマスはほとんどなく、「書かれていない」と断定する場面が少ない。分けるための項目と決まりを増やすほどの理由がない。

## 影響

- 採点器は、価格の null を上のとおり扱い、診断に「価格の読み落とし」を記録する。
- 見直すきっかけ：価格が書かれていないマス（「応相談」など、価格が数字で書かれていないものを含む）が、買取表に出てきたとき。そのときは C（「書かれていない」と「読み取れない」を分ける）を検討する。
