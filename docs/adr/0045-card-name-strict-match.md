# 0045. カード名は厳密に比べ、「EX」と「ex」を同じとみなさない。表記だけの違いは診断で分ける

- ステータス：採用
- 日付：2026-10-30
- 決定者：kajiwara
- 関係するADR：[0037](0037-results-and-diagnosis.md)（成績と診断）、[0039](0039-deliverables-and-intermediates.md)（成果物と中間結果）

## 背景

- 設計書 8.2 では、印刷名は「全角・半角、空白、『EX』『ex』などの表記を正規化してから完全一致」とする案だった。どこまで同じとみなすかは、決めていなかった。
- カード名などの自由な値は、正解と違えば、違いとして扱うのが基本である（[0042](0042-out-of-vocabulary-values.md)）。
- 「EX」と「ex」は、表記の違いではない。BW・XY期の「EX」と、SV期の「ex」は、別の種類のカードである。
- 一方で、全角と半角、空白の有無の違いは、画像の読み違いではなく、出力の書き方の違いである。直す部品が違う。
- カード名は中間結果で、成績には直接は効かない（[0039](0039-deliverables-and-intermediates.md)）。診断の材料である。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| A. 正規化してから比べる（設計書の案） | 表記の違いで、読み違いとされない | 「EX」と「ex」のように、意味のある違いまで消える。表記の違いと読み違いが区別できない |
| **B. 厳密に比べる。そのうえで、診断では「表記だけの違い」と「読み違い」を分ける** | 違いを見逃さない。直す部品ごとに分けられる | 採点器の処理が少し増える |

## 決定

**B にする。**

- カード名は、**正規化せずに厳密に比べる。** 「EX」と「ex」も、全角と半角も、違いとして扱う。
- 違っていた場合、診断で次のように分ける。
  - **表記だけの違い**：全角・半角、空白の有無だけを揃えると一致する。直す部品は、出力の書き方（プロンプト）。
  - **読み違い**：それ以外。直す部品は、画像の読み取り。
- 「EX」「ex」などの大文字・小文字は、揃える対象に入れない。違えば、読み違いか知識による補完として扱う。

## 理由

- **意味のある違いを、見逃さないため。** 「EX」と「ex」は別の種類のカードで、同じとみなすと、読み違いや知識による補完を見逃す。A を選ばなかったのはこのため。
- **表記の違いと読み違いでは、直す部品が違うため。** 厳密に比べたうえで、違いを診断で分ければ、どちらを直せばよいかがわかる。
- **カード名は中間結果なので、厳密に比べても、成績を不当に悪くしないため。** 成績は成果物（パック・番号・仕様・価格）で決まる。

## 影響

- 採点器は、カード名を厳密に比べ、違いを「表記だけの違い」と「読み違い」に分けて記録する。
