# 0040. 出力に段階ごとの中間結果を含めさせ、どの段階で外れたかを診断する（価格の文字を足す）

- ステータス：採用
- 日付：2026-10-30
- 決定者：kajiwara
- 関係するADR：[0037](0037-results-and-diagnosis.md)（成績と診断）、[0039](0039-deliverables-and-intermediates.md)（成果物と中間結果）

## 背景

- 診断では、成果物が外れたとき、どの段階で外れたかを見つけたい（[0037](0037-results-and-diagnosis.md)）。段階によって、直す部品が違うため。
- 価格を出すまでには、3つの段階がある。

```
① 位置：どのマスの価格か → ② 読み取り：印刷された文字を読む（「1.5万円」）→ ③ 換算：円の整数にする（15000）
```

- 今の出力は、最後の `price_jpy` しか持っていない。そのため、価格が外れても、②の読み違いか③の換算の誤りかを区別できない。
- カードの特定は、すでに段階を分けられる形になっている。`printed`（印刷されたカード名・HP・ワザ）と `identification`（パック・番号）を分けているので、「読み取りの誤り」と「照合の誤り」を区別できる（設計書 5.2）。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| A. 最終の値だけを出させる（今の価格） | 出力が小さい | どの段階で外れたかがわからない。数値のずれ方（10倍など）から推し量るしかない |
| **B. 段階ごとの中間結果も出させる** | どの段階で外れたかを、機械で判定できる | 出力が増える。中間結果を出させること自体が、モデルの考える道筋を少し決める |

## 決定

**B にする。**

- **原則：出力に、段階ごとの中間結果を含めさせる。採点器は、中間結果と正解を段階ごとに比べ、どの段階で外れたかを診断する。**
- 価格について、出力に `printed.price_text`（印刷されている通りの価格の文字。例：「1.5万円」）を足す。価格が書かれていない、または読めないときは null。
- 正解データに `price_text` の列を足す。
- 価格の診断は、次のように判定する。

| 判定 | 外れた段階 | 直す部品 |
|---|---|---|
| 出力の価格が、隣のマスの正解の価格と一致する | ① 位置 | 格子の把握（H1：分割） |
| `price_text` が正解と違う | ② 読み取り | 画像の読み取り |
| `price_text` は正解と同じなのに、`price_jpy` が違う | ③ 換算 | 換算の決まりの伝え方（プロンプト） |

- カードの特定は、今の項目のまま、次のように判定する。

| 判定 | 外れた段階 | 直す部品 |
|---|---|---|
| 印刷名・HPが正解と違い、パック・番号も違う | 読み取り | 画像の読み取り |
| 印刷名・HPは正しいのに、パック・番号が違う | 照合 | 照合（H2：カードDB検索）、自己検証（H3） |

## 理由

- **直す部品を、段階ごとに特定するため。** 同じ「価格が違う」でも、位置の取り違え、読み違い、換算の誤りで、直す部品が違う。A では区別できない。
- **機械で判定できるようにするため。** 中間結果があれば、正解と比べるだけで段階がわかる。数値のずれ方から推し量るのは、あてにならない。
- **中間結果を出させることの影響は、比較を壊さないため。** 中間結果を出させると、モデルの考える道筋（読んでから換算する）が少し決まる。ただ、すべての被験ハーネスに同じ出力の形を求めるので、ハーネスどうしの比較は公平なままである。
- **この原則は、タスクに依存しないため。** ほかのタスクでも、成果物を作る段階を決め、段階ごとの中間結果を出させれば、同じように診断できる。

## 影響

- `output.schema.json` の `printed` に `price_text` を足す（必須。値は文字か null）。
- `gold.schema.yaml` に `price_text` の列を足す。`gold-draft/prompt.md` の列にも足す。
- `spec.yaml` の R-03 に、印刷されている通りの価格の文字も出すことを書く。
- 1枚目のサンプル（`magi-nagoya-20261030`）の正解データに、`price_text` を足す。
- ほかの段階（カードの特定の候補の数など）の中間結果を足すかは、診断で区別できないことが出てきたときに決める。
