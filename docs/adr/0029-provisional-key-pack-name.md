# 0029. 仮のキーのパックの名前は、公式の商品名から決まった語を外してそろえる

- ステータス：提案
- 日付：2026-10-29
- 決定者：kajiwara（未決定。PRでレビューする）
- 関係するADR：[0026](0026-provisional-key-pack-number-variant.md)（仮のキーは「パック＋番号＋仕様」）
- 調査：[docs/research/card-data-sources.md](../research/card-data-sources.md)

## 背景

- 仮のキーの1つ目の要素は、パック（カードが入っていた商品）にする（[0026](0026-provisional-key-pack-number-variant.md)）。
- パックの名前は、サイトや買取表によって書き方が違う（調査の5章）。
  - 公式：「ポケモンカードゲームBW 拡張パック「ブラックコレクション」」
  - 遊々亭：`bw01b`（ページのURL）
  - ネットオフ：「[ホワイトコレクション] BW1」
  - モデルの出力：「拡張パック「プラズマゲイル」」「プラズマゲイル」など
- 採点器は仮のキーを文字列として比べるので、書き方がゆれると、合っているのに誤答になる。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| A. 公式の商品名をそのまま使う | 決め方がはっきりしている | 長い。モデルも人も、毎回同じ書き方で書くのが難しい。公式にないパックやプロモでは決められない |
| **B. 公式の商品名から、決まった語を外してそろえる** | 短く、モデルも人も書きやすい。外す語を決めれば、機械でそろえられる | 外す語の一覧と、公式にないパックの名前の付け方を決める必要がある |
| C. 自分で決めた記号を使う（`BW1-B` など） | 短く、ゆれない | モデルは記号を知らないので、名前から記号に直す仕組みが要る。M0では作りすぎ |

## 決定

**B にする。** パックの名前は、公式の商品名から、次の語を外したものにする。

| 外す語 | 例 |
|---|---|
| シリーズの名前（「ポケモンカードゲームBW」など） | 「ポケモンカードゲームBW 拡張パック「ブラックコレクション」」→「ブラックコレクション」 |
| 商品の種類（「拡張パック」「強化拡張パック」「コンセプトパック」など） | 「拡張パック「プラズマゲイル」」→「プラズマゲイル」 |
| かぎかっこ（「」） | 同上 |

- プロモは、世代の名前に「プロモ」を付ける（例：「BWプロモ」）。番号に `BW-P` などの記号が入るので、番号と合わせて一意になる。
- 公式に載っていないパックや、商品名がはっきりしないものは、正解データの作り手が名前を決め、タスクごとの一覧に書く。
- 採点器は、出力のパックの名前に、同じ外し方をしてから比べる。モデルが「拡張パック「プラズマゲイル」」と書いても、「プラズマゲイル」と書いても、同じものとして扱う。

## 理由

- **A を選ばなかったのは、書き方を毎回そろえるのが難しいため。** 公式の商品名は長く、シリーズの名前の書き方もゆれやすい。モデルが正しいパックを答えていても、文字が少し違うだけで誤答になる。誤答を最も重く見るこのタスクで、書き方のゆれを誤答に数えるのは避けたい。
- **外す語を決めて、機械でそろえるため。** 外す語の一覧があれば、採点器が出力を同じ形に直してから比べられる。「どこまで同じとみなすか」が、人の判断ではなく決まりになる。
- **C を選ばなかったのは、M0では作りすぎのため。** 記号を使うには、名前と記号の対応表と、モデルの出力を記号に直す仕組みが要る。それはM1のカードDBが受け持つこと。

## 決めるために必要なこと

- **外す語の一覧で足りるか。** 正解データを作るときに、最初の題材のパックの名前で試し、足りなければ足す。
- **パックの名前の一覧を、どこに置くか。** 案：タスクごとのフォルダ（`tasks/<タスク名>/`）に置く（[0016](0016-task-folder-per-task.md)）。

## 影響

- 正解データの作成ルール（`docs/gold-guideline.md`）に、パックの名前のそろえ方を書く。
- 採点器に、パックの名前をそろえる処理を足す。印刷名のそろえ方（全角・半角、空白など。設計書 8.2）と同じ場所に置く。
- タスク仕様（`docs/task-spec.md`）に、パックの名前の書き方の例を載せる。ただし、採点器がそろえるので、モデルには厳しく求めない。
- 見直すきっかけ：M1でカードDBを作り、パックに `card_id` の一部となる記号を付けるとき。
