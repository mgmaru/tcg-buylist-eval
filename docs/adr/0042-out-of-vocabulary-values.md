# 0042. 語彙の外の値は、仕様の軸ならその軸だけ「指定なし」として扱い、出てきた値を記録する

- ステータス：採用
- 日付：2026-10-30
- 決定者：kajiwara
- 関係するADR：[0027](0027-provisional-key-variant.md)（仕様の軸）、[0038](0038-score-by-assertion.md)（正解・保留・誤答）、[0041](0041-format-error-kinds-and-units.md)（形式の誤りの種類）、[0043](0043-vocabulary-from-concepts.md)（語彙の一覧）

## 背景

- 出力の値には2種類ある。
  - **自由な値**：カード名、価格、パック、番号など。一覧はなく、正解と違えば、そのまま違いとして扱う。
  - **語彙の値**：`status`、仕様の軸（版・加工・スタンプ）。一覧（`enum`）の中から選ぶ。
- 語彙の値が一覧の外にあるとき（例：`"finish": "ミラー"`）の、成績での扱いを決める必要があった（[0041](0041-format-error-kinds-and-units.md)）。
- 一覧の外の値は、「間違った値」とは限らない。一覧にある値の言い換えのことも、一覧にない概念のこともある。
- 一覧の外の値を、一覧の中の近い値に直す（丸める）と、間違った具体的な値を作ってしまうおそれがある。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| A. 語彙の外の値があれば、カードごと保留にする | 単純。厳しい | 加工の言い方が違うだけで、正しく特定したカードまで保留になる |
| **B. 仕様の軸なら、その軸だけ「指定なし」として扱う。`status` なら、カードを保留にする** | 誤りの影響が、その軸だけに留まる。必ず「わからない」の側に寄せるので、間違ったデータを作らない | 決まった手順の読み替えを、採点器に入れる必要がある |
| C. 一覧の中の近い値に直して採点する | 言い換えを救える | 何を近いとみなすかに判断が入る。間違った具体的な値を作るおそれがある |

## 決定

**B にする。**

- **仕様の軸（版・加工・スタンプ）の値が一覧の外なら、その軸だけ「指定なし」（断定していない）として成績を決める**（[0039](0039-deliverables-and-intermediates.md) の決め方に従う）。
- **`status` の値が一覧の外なら、そのカードを保留にする。** 特定したのか不明なのかが読み取れないため。
- どちらの場合も、形式の誤り（語彙の外）として数え、**出てきた値をそのまま記録する**。
- 一覧の中の値に近いかどうかの判断はしない。

## 理由

- **誤りの影響を、その軸だけに留めるため。** 加工の言い方が違うだけで、正しく特定したカード全体を保留にするのは、成績を大げさに悪くする。A を選ばなかったのはこのため。
- **読み替えは、必ず「わからない」の側にしか寄せないため。** 「指定なし」として扱うのは、断定しなかったのと同じ扱いで、間違ったデータを作ることはない。一覧の中の近い値に直すと、間違った具体的な値を作るおそれがある。C を選ばなかったのはこのため。
- **二重に減点しないため。** 語彙の外は形式の誤りとして数え、合格ラインの `format_errors` で不合格にする。成績のほうでは、その軸を断定しなかったものとして扱うだけにする。
- **出てきた値を記録するのは、** 一覧を直す材料になるため。一覧にある値の言い換えなら、一覧の伝え方（ハーネス）を直す。一覧にない概念なら、一覧（タスク）を直す（[0043](0043-vocabulary-from-concepts.md)）。

## 影響

- 採点器は、語彙の外の値を見つけたら、上のとおり読み替えて成績を決め、診断に値を記録する。
- レポートに、語彙の外で出てきた値の一覧を出す。一覧を直すときの材料にする。
