# 0031. スキーマの種類はデータの形に、ファイルの書き方は読み手に合わせる

- ステータス：採用
- 日付：2026-10-29
- 決定者：kajiwara
- 関係するADR：[0019](0019-gold-schema-machine-readable.md)（正解データの列の定義はYAML）、[0030](0030-task-spec-in-yaml.md)（タスクの仕様はYAML）

## 背景

- タスクには、2つのスキーマがある。
  - `output.schema.json`：被験エージェントの出力（JSON）の形
  - `gold.schema.yaml`：正解データ（`gold.csv`）の列の定義
- 片方はJSON、もう片方はYAMLで書いている。しかし、その理由はどのADRにも書いていなかった。
  - `output.schema.json` は、設計書の最初の案からJSONだった。比べて決めたものではない。
  - [0019](0019-gold-schema-machine-readable.md) は、Markdownか、機械で読める形かを比べてYAMLにした。JSONとYAMLは比べていない。
- 実は、2つの層を分けて考える必要がある。
  - **スキーマの種類**（JSON Schema か Table Schema か）
  - **ファイルの書き方**（JSON か YAML か）。JSON Schema も Table Schema も、どちらの書き方でも書ける。

## 検討した選択肢

| 選択肢 | 良い点 | 弱い点 |
|---|---|---|
| A. すべてJSONで書く | 書き方が1つで済む | 人が読み書きするファイルで、コメントが書けず、読みにくい |
| B. すべてYAMLで書く | 人が読みやすい | モデルの呼び出しや検証の道具に渡すとき、JSONへの変換が要る |
| **C. スキーマの種類はデータの形に、ファイルの書き方は主な読み手に合わせる** | それぞれの使い道で、変換や読みにくさがない | 書き方が2つになる。どちらにするかの決まりが要る |

## 決定

**C にする。**

- **スキーマの種類は、確かめるデータの形に合わせる。**
  - JSON（入れ子のあるデータ）は、JSON Schema で確かめる。例：被験エージェントの出力。
  - CSV（平らな表）は、Table Schema で確かめる。例：正解データ。
- **ファイルの書き方は、主な読み手に合わせる。**
  - **主に機械が読むものは、JSON で書く。** 例：`output.schema.json`。モデルの呼び出し（Anthropic API、Ollama）、検証の道具、採点器が読む。
  - **人が読み書きするものは、YAML で書く。** 例：`gold.schema.yaml`（人が正解データを書くときに読む）、`spec.yaml`、`task.yaml`。

## 理由

- **スキーマの種類をデータの形に合わせるのは、** それぞれの形を確かめるための標準の書き方がすでにあるため。入れ子のあるJSONは JSON Schema、CSVの列は Table Schema で確かめるのが自然で、道具もそろっている。
- **機械が読むものを JSON にするのは、変換の手間とずれをなくすため。** モデルの呼び出しに渡すスキーマも、検証の道具（ajv など）が読むスキーマも JSON。YAMLで書くと、渡すたびにJSONへ直す必要があり、直し方の違いで中身がずれるおそれがある。B（すべてYAML）を選ばなかったのは、このため。
- **人が読み書きするものを YAML にするのは、読みやすく、コメントが書けるため。** 正解データを作る人は、列の定義の `description` を読みながら作業する。タスクの仕様や目録も、人が書いて読む。A（すべてJSON）を選ばなかったのは、このため。
- **書き方が2つになっても C にしたのは、** どちらかに揃えると、機械の側か人の側のどちらかで、変換や読みにくさが出るため。

## 影響

- 今のファイルは、この決まりに合っている。`output.schema.json`（JSON）、`gold.schema.yaml`・`spec.yaml`・`task.yaml`（YAML）。
- これから足すファイルも、この決まりで書き方を選ぶ。たとえば、採点の結果（`metrics.json`）や実行の情報（`run.json`）は、主に機械が読むので JSON。被験構成や被験ハーネスの設定は、人が書くので YAML。
- 見直すきっかけ：人も機械も同じくらい読むファイルが出てきて、どちらにするか迷ったとき。
