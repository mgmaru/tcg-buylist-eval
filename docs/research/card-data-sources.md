# 調査：カードの情報をどこから、どこまで取れるか

調査日：2026-10-29

M0の仮のキー（設計書 2.2）を決めるための調査（[ADR-0026](../adr/0026-provisional-key-pack-number-variant.md)〜[0029](../adr/0029-provisional-key-pack-name.md)）。あわせて、M1のカードDBや Card Pulse で、カードの情報をどこから集められるかの参考にする。

## 結論

- **公式のカード検索には、DP（2006年）より前のカードが載っていない。** 旧裏・neo・VS・e・ADV・PCGのカードは、1枚も見つからなかった。DP以降は、拡張パック・デッキ・プロモ・基本エネルギーまで、合わせて23,492枚が載っている。
- **BW期のシークレットレア（番号が収録数を超えるカード）も、公式には載っていない。** たとえばブラックコレクションは001〜053/053の53枚だけで、レシラムSR（055/053）がない。BW期の拡張パックは、どれも収録数ちょうどの枚数しかない。**XY以降は、シークレットレアも載っている**（XY1は063/060、SV2aは210/165まで）。
- **公式は、1ED・アンリミ・ミラーなどの仕様を区別しない。** 1つのカードに1つのIDがあるだけ。
- **したがって、公式のIDは、BW期の買取表の仮のキーには使えない。** 買取表で高い値が付くのはSR・URが中心なので、公式のIDがないカードが必ず出る。
- **パック＋番号なら、公式以外のサイトでも照合できる。** ショップ（遊々亭、カードラッシュ、ネットオフ）と有志のWiki（ポケモンカードWiki）は、どれもパックと番号でカードを並べていて、シークレットレアも載っている。ただし、**サイトによって載っているカードや仕様の区別が違う** ので、1つのサイトだけで決めず、複数を突き合わせる必要がある。
- **パック＋番号だけでは一意にならない場合がある。** 同じパック・同じ番号でも、1EDとアンリミ、ミラーなどで別のカードとして売られ、価格が違う。仮のキーには **仕様** も含める。
- **カードの番号の付き方は、世代によって違う**（3章）。
  - 旧裏・neo（1996〜2001年）には、番号がない。
  - VS・web・e・ADV・PCG・DPt・LEGEND・BW以降は、パックごとの番号（`001/141` の形）がある。
  - **DP（DP1〜DP5、2006〜2008年）は、パックごとの番号がない。** 代わりに「DPBP#」で始まる **パックをまたいだ通し番号**（1〜530）がある。これは **カードではなくポケモンの種類に付く番号** で、同じポケモンなら別のパックでも同じ番号になる（パルキアはDP1でもDP3でも DPBP#523）。LV.X・トレーナーズ・エネルギーには、この番号もない。
  - **プロモは、どの世代にも番号のないカードがある**（勝利のしるし、基本エネルギーなど）。番号があっても、**同じ番号が複数のカードに付いていることがある**（013/XY-P のデデンネは、配布元のスタンプ違いで4枚ある）。
- **公式サイトのデータは、私的な利用の範囲でしか使えない。** サイトの利用条件で、データの複製・転載・配布が禁じられている。正解データを作るときに **参照する** のはよいとしても、**公式のデータを集めてカードDBにする** のは、利用条件に反するおそれがある。M1でカードDBを作るときは、権利の確認が先に要る。

## 調べ方

- 公式のカード検索が画面の表示に使っている一覧の取得先（`/card-search/resultAPI.php`）から、「すべてのカード」の603ページを取得し、カードごとのIDと画像のファイル名を集めた。リクエストの間は0.2秒あけた。取得したデータはリポジトリに入れていない。
- 画像のファイル名には、エキスパンションの記号が入っている（例：`/card_images/large/BW1-Bb/027113_P_RESHIRAMU.jpg`）。これでエキスパンションごとの枚数を数えた。
- いくつかのエキスパンションで、ID順で最後の数枚の詳細ページ（`/card-search/details.php/card/<ID>/regu/all`）を開き、番号を確かめた。
- ショップとWikiは、BW1（ブラックコレクション、ホワイトコレクション）のページを見て、公式と比べた。
- 1EDの時期は、日本語版の公式の情報が見つからなかったため、海外のコレクターのフォーラムと、ショップの説明を参考にした。
- 番号の付き方（3章）は、次の方法で調べた。
  - DP期（DP、DP1〜DP5、DPP、DPtP の1,014枚）と、BW以降のプロモ（BWP、XYP、SMP、S-P、SV-P、M-P、WCP の2,124枚）は、公式の詳細ページを **全件** 開き、番号の欄を集めた。DPt・LEGENDなどは、6枚ずつ抜き出して確かめた。
  - 公式の画像（小さいもの）で、番号のないカードがどんなカードかを確かめた（DP1のドダイトスLV.X、XY-Pのデデンネなど）。
  - 公式に載っていない世代（旧裏・neo・VS・web・e・ADV・PCG）は、ポケモンカードWikiのカードのページ（「コレクションナンバー」の欄）を、パックごとに12枚ずつ読んだ。VSはショップの出品の表記でも確かめた。

## 1. 公式のカード検索

### 1.1 取れる情報

| 取得先 | 取れる情報 |
|---|---|
| 一覧（`resultAPI.php`） | カードのID、カード名、画像のファイルの場所。1ページに約39枚。全体の件数（`hitCnt`）とページ数（`maxPage`）も返る |
| 詳細のページ（`details.php/card/<ID>/regu/all`） | カード名、番号（例：013/053）、イラストレーター、HP、タイプ、ワザ（名前・ダメージ・効果）、特性、弱点、抵抗力、にげる、進化、収録商品の名前（例：「ポケモンカードゲームBW 拡張パック「ブラックコレクション」」）、レアリティ（画像だけ。文字では書かれていない）、エキスパンションのマーク（画像） |

- 一覧の取得先は、公開された使い方の説明がない、画面の内部の仕組み。予告なく変わることがある。
- キーワードで絞るつもりで `keyword=レシラム` を付けたが、絞り込まれず全件が返った。絞り込みの指定の仕方は確かめていない。
- IDは、登録された順の連番に近い（1〜50811。間に欠けがある）。IDから、パックや番号はわからない。

### 1.2 載っている範囲

| 世代 | 時期 | 公式に載っているか |
|---|---|---|
| 旧裏（第1弾〜neo） | 1996〜2001年 | **載っていない** |
| VS、web、e | 2001〜2003年 | **載っていない** |
| ADV、PCG | 2003〜2006年 | **載っていない** |
| DP、DPt、LEGEND | 2006〜2010年 | 載っている（DP1〜DP5、DPt1〜DPt4、L1〜L3、デッキ、プロモ「DPP」「DPtP」） |
| BW | 2010〜2013年 | 載っている。**ただしシークレットレアはない**（1.3） |
| XY 〜 今 | 2013年〜 | 載っている。シークレットレアも載っている |

- エキスパンションの記号は、公式の画像のフォルダの名前による。たとえば、ブラックコレクションは `BW1-Bb`、ホワイトコレクションは `BW1-Bw` で、**同じ「BW1」でも、公式は別のパックとして扱っている。**
- プロモは、世代ごとにまとめられている：`DPP`（175枚）、`DPtP`（65）、`BWP`（246）、`XYP`（466）、`SMP`（443）、`S-P`（334）、`SV-P`（322）、`M-P`（205）。大会のプロモ（`WCP`、108枚）や基本エネルギー（`ENE`、85枚）もある。

### 1.3 シークレットレアの扱い

エキスパンションごとの、公式に載っている枚数と、ID順で最後のカードの番号：

| エキスパンション | 公式の枚数 | 最後のカードの番号 | シークレットレア |
|---|---|---|---|
| BW1 ブラックコレクション（`BW1-Bb`） | 53 | 053/053 | **ない**（ショップとWikiには 054/053、055/053 がある） |
| BW1 ホワイトコレクション（`BW1-Bw`） | 53 | — | **ない**（同上） |
| BW7（`BW7-B`） | 70 | — | **ない** |
| BW8（`BW8-Brf`） | 51 | 051/051 | **ない** |
| BW10（`BW10-B`） | 93 | 093/093 | **ない** |
| XY1（`XY1-Bx`） | 63 | 063/060 | ある |
| XY8（`XY8-Br`） | 64 | 064/059 | ある |
| SM1（`SM1M`） | 66 | 066/060 | ある |
| SM8b（`SM8b`） | 243 | 243/150 | ある |
| SV2a（`SV2a`） | 210 | 210/165 | ある |

- BW期のほかの拡張パックも、公式の枚数が収録数と同じだった（BW2：66、BW3：52ずつ、BW5：50ずつ、BW6：59ずつ、BW9：76など）。BW期では、シークレットレアがまとめて載っていないと考えられる。
- XY1は、最後が063/060。XY1のシークレットレアがすべて載っているかは確かめていない。

### 1.4 区別しないもの

- **1EDとアンリミ**：1つのカードに1つのIDだけで、区別はない。
- **ミラー**（SV2aのマスターボールミラーなど）：SV2aは210枚（165枚＋シークレットレア45枚）で、ミラーは別に載っていない。
- **同じカードが別の商品に入った場合**：番号が違えば、別のカードとして別のIDが付く（例：レシラムは `BW1-Bb`、`BW8-Brn`、`BW10-B`、`BWP` に別々にある）。

### 1.5 利用の条件

公式サイトの「サイトのご利用」（`/policy.html`）による。

- サイトのデータの著作権は、株式会社ポケモンにある。
- データは、**個人的に楽しむ場合に限って** 使ってよい。
- データのコピー、複製、改変、出版、掲示、電送、配布は断っている。インターネットなどの公衆ネットワークの上で使うこともできない。
- 画像その他の内容の無断転載は断っている。
- 機械での取得（スクレイピング）については、書かれていなかった。`robots.txt` もない（トップページが返る）。

**正解データを作るときに、人が公式を見てパックと番号を確かめる** のは、M0の進め方の通り。ただし、正解データをリポジトリで公開するか（TODO 1.4）、公式のデータを集めてカードDBにするか（M1）は、この条件を踏まえて 👤 が確かめる（TODO 2章）。

## 2. 公式以外のサイト

BW1（ブラックコレクション）で比べた。

| サイト | 種類 | パック・番号 | シークレットレア | 1ED・アンリミ | 古いカード |
|---|---|---|---|---|---|
| 遊々亭 | ショップ（販売） | パックごとのページ（`bw01b`、`bw01w`）。番号、レアリティ、カード名、価格、在庫 | 載っている（054/053 トルネロスSR、055/053 レシラムSR） | **BW期は区別しない** と明記 | （確かめていない） |
| カードラッシュ | ショップ（販売） | 商品名に `{019/106}` のように番号を書く | （確かめていない） | **商品名に「(1ED)」「(アンリミ)」を書いて区別する**。書いていなければ「1EDではないもの、または選べないもの」 | 載っている（例：エンテイ☆ 019/106） |
| ネットオフ | ショップ（買取） | 「ゼクロム SR [ホワイトコレクション] BW1 055/053」のように、レアリティ・パック・型番・番号を書く | 載っている | （確かめていない） | （確かめていない） |
| ポケモンカードWiki | 有志のWiki | パックごとのページに番号の一覧。発売日もある | 載っている（054/053 トルネロスSR、055/053 レシラムSR、**056/053 ピカチュウUR**） | 書かれていない | パックの一覧がある |
| ポケモンカード 旧シリーズ検索（pcg-search.com） | 有志の検索 | 旧裏・neo・VS・e・ADV・PCGに絞った検索 | （確かめていない） | （確かめていない） | **公式にない世代を補う** |

- **サイトによって、載っているカードが違う。** ブラックコレクションのピカチュウUR（056/053）は、ポケモンカードWikiにはあるが、遊々亭のページには見当たらなかった。1つのサイトだけでは、抜けに気づけない。
- **サイトによって、仕様の区別が違う。** 遊々亭はBW期の1EDを区別しないが、カードラッシュは区別する。買取表も、店によって区別したりしなかったりすると考えられる。
- カードラッシュの `robots.txt` は、AIの学習用のクローラー（GPTBotなど）を断っている。遊々亭の `robots.txt` は、一部のクローラーに取得の間隔を求めている。機械で取得するときは、サイトごとに確かめる。

## 3. 番号の付き方（世代ごと）

### 3.1 拡張パック・デッキ

| 世代 | 時期 | 番号の形 | 例 | 調べた先 |
|---|---|---|---|---|
| 旧裏（第1弾〜、拡張シートなど） | 1996〜2000年 | **番号なし** | — | Wiki（コレクションナンバーの欄が空）。カードラッシュは番号の代わりに `{旧裏}` と書く |
| neo | 2000〜2001年 | **番号なし** | — | Wiki（同上）。カードラッシュも `{旧裏}` |
| VS | 2001年 | パックごと | `001/141` | Wiki、ショップの出品 |
| web | 2001〜2002年 | パックごと | `025/048` | Wiki |
| e | 2001〜2003年 | パックごと。**キラとノンキラで別の番号** | `071/128`（リザードン、ノンキラ）、`103/128`（同、キラ） | Wiki |
| ADV | 2003〜2004年 | パックごと | `015/055` | Wiki |
| PCG | 2004〜2006年 | パックごと | `050/075` | Wiki |
| DP（DP1〜DP5、DPのデッキ） | 2006〜2008年 | **パックごとの番号なし。** ポケモンには「DPBP#」の通し番号 | `DPBP#450`（ドダイトス） | 公式（全件）、Wiki |
| DPt（DPs〜DPt4） | 2008〜2009年 | パックごと | `025/090` | 公式 |
| LEGEND | 2009〜2010年 | パックごと。**2枚で1体のLEGENDのカードは、上と下で別の番号** | `070/080`（上）と `071/080`（下） | 公式、Wiki |
| BW〜今 | 2010年〜 | パックごと。シークレットレアは収録数を超える番号 | `055/053` | 公式、ショップ、Wiki |

### 3.2 DP期の「DPBP#」

ポケモンカードWikiでは「基本コレクションナンバー」と呼ばれ、「DPシリーズでポケモンのカードの通しナンバー。ポケモンLV.Xなどこれが無いポケモンもいる」と説明されている。公式のDP期の全件（1,014枚）を見ると、次のようになっていた。

| 項目 | 結果 |
|---|---|
| 番号の範囲 | DPBP#001〜#530（529種類）。DP1〜DP5のどのパックも、この範囲の中から飛び飛びに使っている（DP1は#036〜#529） |
| 何に付くか | **ポケモンの種類に1つ。** 同じ番号に、違う名前のカードはなかった。同じ名前に、違う番号もなかった。例：#001 フシギダネ、#025 ピチュー、#026 ピカチュウ、#530 ダークライ（全国図鑑の番号とは違う） |
| パックをまたいだ重なり | **ある。** パルキアはDP1でもDP3でも #523。ディアルガも同じ |
| 同じパックの中の重なり | **ある。** DP2のピカチュウ（#026）は2枚登録されていて、絵の切り取り方が違う。アンノーン[M]（#241）なども同じ |
| 番号のないカード | DP1〜DP5で166枚。LV.X（例：ドダイトスLV.X）、トレーナーズ、エネルギー。DPのデッキ（公式の記号 `DP`）は42枚すべて番号なし |
| ショップの表記 | 出品の番号の欄に `DPBP#450` のように書くところが多い |

**DPBP#は、カードではなくポケモンを表す番号なので、パック＋DPBP#でも、カードは一意に決まらない。**

### 3.3 プロモ

| 世代 | 番号の形 | 番号のないもの（公式の全件） | 同じ番号が複数のカードに付く例 |
|---|---|---|---|
| 旧裏期 | **番号なし** | すべて | — |
| VS〜e期（P、J、Tなど） | 確かめていない | — | — |
| ADV〜PCG（ADV-P、PCG-P） | `068/PCG-P` の形（Wikiの記事名による） | 確かめていない | — |
| DP（DP-P） | `001/DP-P` | 175枚のうち48枚（映画の配布カード、トレーナーズ、エネルギーなど） | — |
| DPt（DPt-P） | `001/DPt-P` | 65枚のうち14枚 | — |
| BW（BW-P） | `001/BW-P` | 246枚のうち17枚（ビクトリーカップ、グッズなど） | — |
| XY（XY-P） | `001/XY-P` | 466枚のうち156枚（基本エネルギー、トレーナーズなど） | **あり**：013/XY-P のデデンネは4枚。カードの中身は同じで、配布元のスタンプ（コロコロ、ポケモンパンなど）だけが違う |
| SM（SM-P） | `001/SM-P` | 443枚のうち36枚（勝利の勲章、ふしぎなアメなど） | — |
| S（S-P） | `001/S-P` | 334枚のうち18枚（勝利の証、基本エネルギーなど） | — |
| SV（SV-P） | `001/SV-P` | 322枚のうち50枚（勝利のしるし、基本エネルギーなど） | — |
| MEGA（M-P） | `001/M-P` | 205枚のうち30枚（勝利のしるし） | — |

- 公式では、番号のないプロモは、番号の欄が空か、`XY-P` のように記号だけが入っている。
- 公式のプロモの記号（`M-P` など）には、別の商品の番号（`001/023`）のカードも入っていた。公式の記号は、商品の単位と一致しないことがある。
- 公式のデータにも、誤記らしきものがある（`127XY-P` のように「/」がない）。

## 4. カードを一意に決めるのに要るもの

| 例 | 起きること | 必要な要素 |
|---|---|---|
| レシラムが3枚（サンプルの買取表） | カード名だけでは決まらない | パック |
| BW1の055/053 | ブラックコレクションとホワイトコレクションは、どちらも型番が「BW1」で、収録数も053。055/053はブラックではレシラムSR、ホワイトではゼクロムSR | パックは **型番ではなく商品** の単位にする |
| プロモ | 番号が「001/BW-P」のように、プロモの記号を含む | 番号を印刷の通りに持つ |
| 1EDとアンリミ | 同じパック・同じ番号で、価格が違う | 仕様 |
| ミラー | 同じパック・同じ番号で、別のカードとして売られる | 仕様 |
| プロモのスタンプ違い | 013/XY-P のデデンネのように、同じ番号でスタンプだけが違う | 仕様 |
| eのキラとノンキラ | 同じカードでも、キラとノンキラで番号が違う | 番号で区別できる（仕様は要らない） |
| 旧裏・neo、番号のないプロモ | 番号がない | パック＋番号では表せない |
| DP1〜DP5 | パックごとの番号がない。DPBP#はポケモンに付く番号で、同じパックの中でも重なる | パック＋番号では表せない |

### 1EDの時期（参考）

- 日本語版の1EDは、VS（2001年）から、XYの20th Anniversary（CP6）までとされる。サン＆ムーン以降には1EDがない。
- BW期とXY期は、ほとんどの拡張パックに1EDとアンリミの両方がある。アンリミは、1EDの2〜3年あとに刷られ、数が少ない。
- 1EDだけのパック（BW4ダークラッシュ、コンセプトパックなど）もあるとされる。ただし、フォーラムの中でも意見が分かれている（CP6はアンリミだけ、という投稿もある）。
- どれも海外のコレクターのフォーラムと、ショップの説明による。公式の情報ではない。

## 5. 今後のアプリ開発への示唆

M1のカードDBと、Card Pulseのデータの取り込みに関わること。

- **公式だけでカードDBは作れない。** DPより前の世代と、BW期のシークレットレアが抜ける。BW期の買取表では、高い値が付くカードほど抜けやすい。
- **公式のIDは、主キーにせず、参照用の列として持つ** のがよい。DP以降の通常のカードには公式のIDがあり、カードの印刷内容（HP、ワザ）を確かめるのに使える。ただし、ないカードもある。
- **カードの単位は「パック＋番号＋仕様」になる。** 公式は「パック＋番号」の単位で、仕様を区別しない。価格はショップごとに「パック＋番号＋仕様」の単位で付く。カードDBの `card_id` は、仕様まで区別できる形にする必要がある。
- **ただし、番号ですべてのカードを表すことはできない。** 旧裏・neo、DP1〜DP5、番号のないプロモ（どの世代にもある）は、パック＋番号で表せない。カードDBでは、`card_id` を番号から作らず、DBが自分で発行するのがよい。
- **番号は「印刷されている番号」として、そのまま持つのがよい。** 番号の形が世代で違う（`001/141`、`001/BW-P`、`DPBP#450`、なし）。番号の形の種類（パックごと、プロモ、DPBP#、なし）を別に持てば、番号で照合できるカードとできないカードを分けられる。
- **DPBP#は、カードではなくポケモンの属性として扱う。** 同じポケモンなら、パックをまたいで同じ番号になるため。
- **スタンプも仕様に入る。** プロモでは、同じ番号でスタンプだけが違うカードがある。
- **複数のサイトを突き合わせる仕組みが要る。** サイトごとに抜けや区別の違いがある。カードの一覧は、公式・Wiki・ショップの和集合で作り、どのサイトに載っていたかを残すとよい。
- **パックの名前は、サイトごとに書き方が違う。** 公式は「ポケモンカードゲームBW 拡張パック「ブラックコレクション」」、遊々亭は `bw01b`、ネットオフは「[ホワイトコレクション] BW1」。サイトをまたいで照合するには、パックの名前の対応表が要る。
- **権利の確認が先。** 公式のデータは私的な利用に限られる。ショップのデータにも、それぞれの利用条件がある。カードDBを作る前に、どのデータをどう使ってよいかを確かめる。

## 6. わからないこと・確かめること

| わからないこと | 確かめ方 |
|---|---|
| 公式の一覧で、キーワードやパックで絞り込む指定の仕方 | 検索の画面の通信を見る |
| XY期のシークレットレアが、公式にすべて載っているか | XY1などで、Wikiの一覧と突き合わせる |
| 旧裏・neo・DP期のカードに、番号が印刷されているか | 実物の画像と、旧シリーズ検索で確かめる |
| 日本語版の1EDの正確な時期と、1EDだけのパック | 実物、またはショップの表記を、パックごとに確かめる |
| 公式とショップのデータを、カードDBに使ってよいか | 各サイトの利用条件を 👤 が確かめる（TODO 2章） |
| 旧裏・neoのカードに、図鑑番号（Wikiの「ナンバー」の欄）が印刷されているか | 実物の画像で確かめる |
| VS〜e期のプロモ（P、J、Tなど）と、ADV〜PCG期のプロモの番号の形 | Wikiのプロモの一覧、実物の画像で確かめる |
| DP2のピカチュウ（#026）が2枚あるのは、何が違うのか（収録された商品か、印刷の違いか） | 公式の画像を大きくして比べる。ショップの表記を見る |
| DP期に1EDがあるか | ショップの表記を見る |
